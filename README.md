🎓 SCRIET EVENTS – College Event Management System

SCRIET Events is a real-time college event management platform built using Flutter and Firebase.
It provides a centralized digital solution for managing college events, registrations, attendance and notifications.

QR based passes are generated

Notifications are sent instantly

📌 Project Impact

SCRIET Events removes paper forms, WhatsApp confusion and fake entries by providing a secure, centralized, and real-time digital system for college event management.
